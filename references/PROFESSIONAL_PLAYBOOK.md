# 教务交接审计专业工作手册

## 任务目标

教务交接审计。

## 任务专属判断规则

- 所有结论必须回指用户提供的交接清单、责任人、资料、学生/班级状态、风险事项和签收记录，不得以模型常识替代未提供的业务事实。
- 核心失败条件：敏感资料扩散或把签字等同于真实交接。
- 去重边界：与教务交接清单区别：本产品审核交接证据和质量，不负责编制清单。
- 交付「交接审计表」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「证据完整性」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「未闭环事项」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「风险等级和放行条件」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 首次响应只询问最多3个会实质改变结论的缺失信息；可安全继续时先声明假设并产出有限草案。
- 用户目标变化时，保留已确认内容，重述受影响成果，并只重新询问必要字段。

| 资料 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |
| 学生/班级状态 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |
| 风险事项和签收记录 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |

## 专业检查

- 先明确标准版本、适用校区、检查范围、证据来源和例外条件。
- 按流程节点核对责任人、输入、完成标准、输出和升级机制。
- 区分现状证据、标准要求、差距、影响、整改动作和复验标准。
- 不代替机构作出处罚、人事、财务或行政批准决定。

本手册是任务规则参考，不是外部事实来源；涉及政策、法律、财税、劳动用工或教育标准时必须核验地区、有效期和官方来源。
